# 🚀 Medusa v2 Headless E-Commerce Monorepo with AI Shopping Assistant

[![Medusa v2](https://img.shields.io/badge/MedusaJS-v2.0-818CF8?style=for-the-badge)](https://medusajs.com/)
[![Next.js 14](https://img.shields.io/badge/Next.js-14.x-000000?style=for-the-badge&logo=nextdotjs&logoColor=white)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.x-3178C6?style=for-the-badge&logo=typescript&logoColor=white)](https://www.typescriptlang.org/)

Hệ thống Thương mại Điện tử Kiến trúc Headless (Headless E-Commerce) xây dựng trên khung **Medusa v2 Monorepo**. Tích hợp **Trợ lý AI Chatbot tư vấn mua sắm** thông minh và phân tích chi phí mua hàng.

---

## ✨ Tính Năng Nổi Bật

- ⚡ **Medusa v2 Engine:** Xử lý đơn hàng, kho hàng, biến thể sản phẩm và thanh toán nhanh chóng.
- 🤖 **AI Customer Service Chatbot:** Trợ lý AI tự động gợi ý sản phẩm dựa trên nhu cầu của khách hàng.
- 🛒 **Storefront Next.js 14:** Giao diện mua sắm mượt mà, tối ưu hóa tốc độ tải trang và SEO.

---

## 🚀 Cài Đặt & Chạy Lập Trình

```bash
git clone https://github.com/nguyenhuynhdt37/medusa-ecommerce-store.git
cd medusa-ecommerce-store
npm install
npm run dev
```
