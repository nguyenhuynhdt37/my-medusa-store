---

## ✨ Tính Năng Nổi Bật

- ⚡ **Headless E-Commerce:** Kiến trúc Headless Commerce linh hoạt với Medusa v2 Engine.
- 🤖 **AI Shopping Assistant:** Chatbot AI hỗ trợ khách hàng tìm kiếm và tư vấn cấu hình sản phẩm phù hợp.
- 📊 **AI Cost Analytics:** Phân tích chi phí và hành vi mua sắm.

```bash
git clone https://github.com/nguyenhuynhdt37/medusa-ecommerce-store.git
cd medusa-ecommerce-store
npm install
npm run dev
```
